**PSXS5 2.2.1**: automatic PS5 user profiles.

## Profiles

-   **Match PS5 user automatically** (Settings → System, on by default): each PS5 account gets its own saves, states, settings and RetroAchievements sign-in when they launch PSXS5. The first account keeps the main profile and existing data at the data root, other accounts use their own folder under `profiles/`.
-   Turn the option off to pick a profile manually in **Who's playing**, as before.

Everything in [2.2.0](https://github.com/SynoPiia/PSXS5/releases/tag/v2.2.0) is unchanged otherwise.
