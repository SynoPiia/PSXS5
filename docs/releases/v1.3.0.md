**PSXS5 1.3.0** (in progress): your own covers, and clearer setup.

## New in 1.3

- **Your own covers** (suggested in [#1](https://github.com/SynoPiia/PSXS5/issues/1)):
  - **By name:** put an image in `/data/PSXS5/covers/` named like the game's title, its disc file or its serial (`Crash Bandicoot.png`, `SCUS-94900.jpg`) and it is used automatically. An image named like the disc file in the game's own folder works too.
  - **By hand:** on the shelf, press △ (Details), then □. Choose any image from `covers/` or the game's folder, with a preview. *Automatic* goes back to the normal cover.
  - Your images are never moved or renamed: a picked cover is copied to `covers/custom/`.
- **Where games and the BIOS go:** the empty shelf now shows both folders, and the README's *Getting started* walks through them step by step.

## Fixes

- **RetroAchievements:** discs are identified correctly (the disc hash read the wrong sectors before).

## Install or update

- **From 1.1 or newer:** Settings → About → *Check for updates*. This needs `/data` unlocked through etaHEN.
- **By hand:**
  1. Extract `PSXS5-v1.3.0.zip`.
  2. Copy `PPSA97510` to `/data/homebrew/` on the PS5, with permissions `777`. Or run:
     ```bash
     python tools/psxs5_sync.py app --app-dir PPSA97510 --host <PS5 IP>
     ```
  3. Close PSXS5 completely (PS button → Close Game) and start it again.

Your games, saves, states and settings stay as they are.

> No BIOS files, games or keys are included, and none will be provided.
