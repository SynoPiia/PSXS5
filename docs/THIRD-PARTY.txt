PSXS5 contains, built into eboot.bin:

PCSX-ReARMed (PlayStation emulator)
  GNU GPL v2 or later - COPYING-pcsx_rearmed.txt
  https://github.com/libretro/pcsx_rearmed

Beetle PSX HW (Mednafen PSX, libretro port, PS5 fork by Mihawk-99)
  GNU GPL v2 or later (Mednafen); the Vulkan renderer (parallel-psx / rhi) is MIT
  COPYING-beetle-psx.txt
  https://github.com/mihawk-99/PS5_BeetlePSX, https://github.com/libretro/beetle-psx-libretro

RADV, Mesa's Vulkan driver for AMD GPUs (PS5 port by Mihawk-99)
  MIT License
  https://gitlab.freedesktop.org/mesa/mesa

rcheevos (RetroAchievements)
  MIT License - LICENSE-rcheevos.txt
  https://github.com/RetroAchievements/rcheevos

SDL 2 - zlib License - https://www.libsdl.org
Fonts in assets/fonts - SIL Open Font License 1.1 (notices beside them): Inter, Noto Sans JP,
  Chakra Petch, IBM Plex Sans, IBM Plex Mono, Fraunces, Work Sans; Tabler Icons - MIT License
Game artwork borders are downloaded on the console from The Bezel Project
  (https://github.com/thebezelproject), as covers are; PSXS5 doesn't include them.
dlmalloc (Doug Lea) - public domain (CC0)
miniz - MIT License - https://github.com/richgel999/miniz
QR Code generator (Nayuki) - MIT License - https://github.com/nayuki/QR-Code-generator
stb_image, stb_truetype (Sean Barrett) - public domain / MIT
Lapy helper - MIT License - Lapy-MIT.txt
libcurl, OpenSSL, libpsl, zstd, libsamplerate (PacBrew packages) - each under its own permissive licence

Downloaded at run time, not included:
  covers - xlenore/psx-covers (https://github.com/xlenore/psx-covers)
  cheats - libretro-database (https://github.com/libretro/libretro-database)

No BIOS, game, key or copyrighted data is included.
